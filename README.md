# 今年つくったもの年表

2026-12-22 担当のアドベントカレンダーに出す、今年作ったアプリ・ページ20件の年表ページ。縦の線に日付を置いて左右交互に並べる1ページ。上に固定した月の色帯・回る数字・小さな実物（得点板・暗記カード・かいもの。本物の見た目と動きを写した小型版）が動く。表紙は作った20件が落ちてきて月ごとの棒グラフに積み上がる。年表の項目はスクロールに合わせて下から現れ、一言だけを見せる。「くわしく読む」で原稿の全文が伸びて開く。年表の終わりは点線が下へ続き「12月へつづく」と出る。12月に作ったものは原稿に「## 12月」の節を足して取り込めば出る。最後は黒い画面いっぱいに作った物（出演）とクレジット（スタッフ・スペシャルサンクス・制作委員会）を流すエンドロールで締める。表紙の題の下に、どのアドベントカレンダーの何日目かを一言で出す。エンドロールの下に、同時に開いている3つの企画の前の日・次の日（ほかの2企画は同じ日も）の記事へのリンクを置く（中身は `src/data/advent.json` に書く。題とリンクがそろうまで「準備中」、担当者がいなければ「まだ空いている日」と出る）。一番下に「上に戻る」ボタンがある。

- 公開中: https://iiiitiiitiiti.github.io/tsukutta-2026/ （2026-11-05 にリポを public にして Pages を有効にした。アドベントカレンダーの公開日 12/22 までは調整中の版）
- プラン: [docs/plan.md](docs/plan.md)

## 本文の直し方

本文の正本は note-articles の `essay/今年つくったもの.md`。記事レビュー帳で削ったら、ここで取り込み直す。

```sh
npm run import            # ../note-articles/essay/今年つくったもの.md を読む
npm run import -- <パス>  # 別の場所の原稿を読む
```

`src/data/timeline.json` が書き換わる。JSON はコミットする（CI は note-articles を読めない）。

取り込みは次のときに止まる。原稿を削って項目を消したら、`src/data/extras.json` からもそのツールを消す。

- extras の `match` に当たる見出しが原稿に無い／複数ある
- 見出しに当たる extras が無い
- 見出しが「○月○日　名前」の形でない、または月の節の外にある

回す数字（extras の `counter`）が本文に同じ形で無いときは警告だけ出す。

## スクショ

`public/shots/<extras の id>.webp`（あれば同名の `.avif` も）を置くと、全文の中の準備中の枠が写真に替わる。年表の丸い小窓はアイコンのまま。冒頭の棚の画像は `tana-overview`。写真は押すと画面いっぱいに大きく出る（`src/components/ShotZoom.astro`）。狭い画面では横にはみ出す大きさで出し、横に動かして見る。

## 日本語のフォント

日本語の字は、このページに出てくる字だけを入れた1ファイル `src/assets/fonts/page-jp.woff2`（約185KB）で出す。Noto Sans JP の全部の字から、ビルド結果に出てくる字と、かな・英数字・約物だけを抜き出したもの。

本文・項目・アドベントカレンダーの題名などを直して新しい字が増えると、`npm run build` が「入っていない字があります」と出して止まる。そのときは次を実行し、`src/assets/fonts/` の2ファイル（`page-jp.woff2` と、入っている字の一覧 `page-jp.json`）をコミットする。

```sh
npm run font
```

初めて実行する機械では、元のフォント（約10MB）を google/fonts の GitHub から取って `.cache/fonts/` に置く（コミットしない）。取るコミットと SHA-256 は `scripts/page-font.mjs` に固定してある。

入力欄に打たれた字など `page-jp.woff2` に無い字は、これまでどおり `@fontsource-variable/noto-sans-jp` の小分けのファイルがその字のぶんだけ届く。決めた経緯は `docs/decisions/019_page-font.md`。

## 共有したときのカード画像

`public/og.png`（1200×630）は表紙の年・題・棒グラフを撮ったもの。12月の節を足すなど棒グラフが変わったら撮り直す。撮り方は `docs/decisions/018_quality-pass.md` に書いた。ブラウザのタブに出る絵は `public/favicon.svg`。

## アクセシビリティの検査

文字は WCAG 2.2 の AA（文字と背景の差4.5:1以上）に合わせている（[docs/decisions/003](docs/decisions/003_wcag-aa-contrast.md)）。色や文字の大きさを変えたら、build したものを preview で動かして検査する。Chrome が要る。

```sh
npx astro preview                                  # http://localhost:4321/tsukutta-2026/
npm run check:contrast                             # 別のターミナルで
npm run check:contrast -- <URL>                    # 別のポートで動かしているとき
```

「くわしく読む」をすべて開いた状態で、幅1280・375・320px の文字の差・押す所の大きさ（24px 以上）・横のはみ出しを数える。Lighthouse は閉じた全文の中を見ないので、こちらで補う。開いてから1.5秒待って測る（中の見本の出だしの動きが終わるのを待つ）。透明で見えていない文字と、読み上げ専用の見えないラベルは数えない。
