## 013. スマホの最初の画面に月まで収め、ホバーをマウスだけにし、項目1つの月は月の数字を横に置く

- 日付: 2026-11-06
- 対象: 表紙（`global.css`・`HeroShelf.astro`）・年表（`index.astro`・`TimelineItem.astro`・`MonthBar.astro`）
- 対象: 見本（`demos/Scoreboard.astro`・`demos/Flashcards.astro`）・ホバーのある全部品・原稿 `note-articles/essay/今年つくったもの.md`

### 決定

- スマホの表紙: 最初の画面に月の数字と数の札まで収める。上の余白88→24px、「2026」を最小96→72px、題の上下28→12px、題とグラフの間48→24px にした。アイコンの丸は画面の高さ（`100svh`）からグラフより上と下の分（約390px）を引いた高さにも合わせ、34pxから最小24pxまで縮む
- ホバー: すべて `@media (hover: hover)` の中に入れ、マウスのときだけ効かせる。表紙の名前の札は `pointerType === 'mouse'` のときだけ出す
- スマホの年表: 月と月の間を約180→約120pxに詰めた。左右の余白を20→16px、線から項目までを56→40px、開いた中身の余白を24→左右16pxにした
- PC で項目が1つだけの月（4月・7月・11月）: 月の数字を上に置かず、項目の反対側の空いている所に並べる。色を移し始める所も区画の半ばへ早める
- 得点板の見本: ルールを5○2✕にした。「1抜け」の札はカードの左上（ロックと優勝の印の反対側）に出す
- 暗記カードの見本: カードの中でスクロールさせない。5枚の裏面でいちばん高いものが収まるよう、幅が変わるたびに見本の高さを伸ばす
- スマホのスクロール: 上の月の帯の後ろをぼかすのを PC だけにした。札が下から上がる幅をスマホだけ64→24pxにした
- 原稿: ウクレレは「前から持っていたのに長く弾かずにいた」とし、9月に始めたという書き方をやめた。「年表の最後は」「冒頭に書いた」「この日は1日で3つ作った。1つ目の」のような記事の語りを項目の文から外した。かいものは「ふたりで」を「複数人で」にした

### 背景

ユーザーが公開中のページをスマホと PC で見て指摘した（2026-11-06・10回目）。

- スマホ: スクロールが滑らかでない。表紙のホバーは要らない。最初の画面に月まで収めたい。月と月の間が広い。線と項目の間を詰めて開いた中身を広くしたい
- PC: 4月の右や7月の左が寂しい
- 見本: 得点板・暗記カード・かいものの直し
- 原稿: ウクレレの時期の訂正

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 全部の月で月の数字を項目の横に置く | 2件目の項目は1件目と高さを120px重ねて反対側に置いている。横に置いた月の数字と2件目がぶつかる。空きが目立つのは項目1つの月だけ |
| 表紙のアイコンを常に小さくする | 背の高いスマホや PC では34px・60pxで収まる。画面の高さで決めれば、低い画面だけ小さくなる |
| アイコンを24pxより小さくして320×568にも収める | 押せる大きさ（24px）を割る。320×568では月の札が69pxはみ出す |
| 「1抜け」の札を本物と同じく名前の下の段に残す | 札が無い間はその段が○の上の空きに見える（ユーザー指摘）。左上は札が無くても空いている |
| 暗記カードの字を小さくして枠に収める | 本物から遠ざかる。前の判断（007）で幅360px以下のときだけ16pxにしている |
| スナップ（エンドロールの近くで止まる仕掛け）を外す | 008 でユーザーが決めた形。止まる所の近くでしか効かない |

### 影響範囲

- スクロールの引っかかりは、この環境では指のスクロールを再現できず、確かめきれていない。ホイールのスクロールでは、ぼかし・スナップ・帯の色・影のどれを外しても、遅れたコマの数はばらつきの範囲（27〜47件）に収まった。ぼかしと札の動きは、スマホで重くなりやすい所として軽くした
- 暗記カードの測り直しは、見た目の指定に使う `data-astro-*` の印を写しに残す。外すと字の大きさが変わり、測った高さがずれる
- 閉じた「くわしく読む」の中では正しく測れないので、見えているとき（`checkVisibility()`）と開いたときにだけ測る
