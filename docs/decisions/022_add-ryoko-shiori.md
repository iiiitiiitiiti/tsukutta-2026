## 022. 旅行のしおりを21件目として足す

- 日付: 2026-11-18
- 対象: 原稿 `note-articles/essay/今年つくったもの.md`・`src/data/extras.json`・`src/data/timeline.json`・`public/shots/ryoko-shiori.webp`・`src/assets/fonts/`・`public/og.png`・`README.md`

### 決定

- 11月11日に作った旅行のしおり（11月14日の日帰りドライブ用の自分用ページ）を、11月の3件目として足した。載せるツールは21件になった。並びは作った日の順で、フォーメーション帳（11月6日）とうんちくネタ帳（11月13日）の間
- 書く中身は本人が選択肢から選んだ（2026-11-18）
  - 一緒に行った相手と誕生日には触れない。「日帰りドライブのしおり」「同行者」とだけ書く
  - 行き先の「大洗」は書く。出発地の町の名前は書かない
  - 当日の話は3つ書く。スマホで見ながら回った・同行者にも見てもらった・予定からずれて帰ってから「実際の一日」を足した
  - 画像は水族館の欄だけを撮って載せる
- 作った日は11月11日とした。相談は11月10日で、しおりのページを作ったのが11月11日（Mac の記録）
- 機能の説明は公開中のしおりのページを読んで書いた（時間割・行き先ごとの欄・お店の候補・雨のときの行き先・天気の欄・「いまここ」の印・「実際の一日」の欄）。当日の出来事は「実際の一日」の欄の記録から拾った（着くのが予定より2時間遅れた・市場と鳥居をやめた）
- アイコンは lucide の `car`
- 画像は、公開中のページを手元に保存してヘッドレス Chrome で描き、水族館の欄の頭に合わせて幅1280・高さ480で撮った（WebP 品質82）。出発地の名前は写っていない
- 新しい字が20字増えたのでページ専用のフォントを作り直した（835字）
- 表紙の11月の列が3つから4つになったので `public/og.png` を撮り直した（撮り方は決定018）
- README の件数を20件から21件に直した（2か所）
- 「おわりに」は変えていない。本人があとで文を調整すると言っているため

### 背景

2026-11-13 に本人が「旅行のあとに足す」と決めていた。11-18 に数字の更新を終えたあと、足すかを聞いて「しおりを足す」と答えをもらった。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 相手や誕生日のお祝いだと書く | 本人が「触れない」を選んだ。かいものも「複数人で使う」としか書いていない |
| 行き先をぼかす | 本人が「大洗と書く」を選んだ。立ち寄り先の名前が出せるほうが中身が伝わる |
| しおりの頭（時間割と天気）を撮る | 時間割と「実際の一日」に出発地の町の名前が出る。住まいが分かる所は写さない決まり |
| 「画像を準備中」の枠にする | ログインなしで撮れて、他人の作ったものも人の情報も写らない欄がある |
| 作った日を相談した11月10日にする | ページができたのは11月11日。ほかの項目も作り始めた日で並べている |
