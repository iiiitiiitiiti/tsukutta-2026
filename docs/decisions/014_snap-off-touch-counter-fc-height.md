## 014. 指で動かす画面ではスナップを外し、数字はふつうのスクロールでは待たずに回し、暗記カードの高さを変えない

- 日付: 2026-11-06
- 対象: `src/styles/global.css`・`src/components/Counter.astro`・`demos/Flashcards.astro`・`demos/Scoreboard.astro`
- 対象: `src/components/Finale.astro`・`src/data/advent.json`・`src/data/extras.json`・原稿 `note-articles/essay/今年つくったもの.md`

### 決定

- スクロール: 指で動かす画面（`pointer: coarse`）では、エンドロールの近くで止まる仕掛け（`scroll-snap-type`）を外す。マウスの画面は 008 のまま
- 回る数字: ふつうのスクロールでは、札が下から上がるのと同じ所（画面の下から1割）で待たずに回す。ページ内リンクで滑って移る間だけ回さず、止まったとき（`scrollend`、来なければ1.5秒後）に見えていたら回す
  - 前は「6割見えてから0.3秒待つ」で、その間000が見えていた
- 暗記カードの見本
  - 答えを出す前と後で下の段の高さを同じにした。ボタンを54pxにそろえ、スワイプの案内は場所を取ったまま見えなくする
  - 「難しい」のボタンで評価したカードは左へ、「わかった」は右へ飛ばす。スワイプは指を動かした向きへ飛ばす
- 得点板の見本: 優勝の札の杯と間を本物より小さくし、それでも枠より高いときは閉じるまで枠を伸ばす
- エンドロール
  - 題を「2026年につくったもの」にした
  - 「出演」から名前までを、ほかの役割と名前の間と同じ10pxにした
  - スペシャルサンクスをユーザー指定の8件に替えた
  - 「製作」を「制作」にそろえ、制作委員会から「〜壁達の福音：Q〜」を外した
- 前後の記事: 序・破・Q の順に並べた。この記事の企画の印は Q に付けたまま
- 原稿
  - Aʻo の意味（ハワイ語で「学ぶ」「教える」。Pukui-Elbert の辞書で確認）を足した
  - ひとつめを今の機能（予定の軸・天気・使用量・ニュース・作問の種・Wikipedia・note・リンク）に合わせて書き直した
  - うごき帳に仕事のデザインの参考にしていることを足した
  - 問題集の下ごしらえに、問題集が BOOTH などでたくさん売られていることを足した

### 背景

ユーザーが公開中のページを見て指摘した（2026-11-06・11回目）。スマホで少しスクロールするとガクっとなる（下のバーが消えると画面が伸びる）。スクロールに違和感が残る。数字の回り始めが遅い。ほかに見本・原稿・エンドロールの直し。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| スナップをどの画面でも残す | スマホのブラウザは、ページ全体に止まる所があると指を離したあとの滑り方が変わる。下のバーの出入りで画面の高さが変わると、止まる所を測り直して跳ねることがある。2回続けてスマホのスクロールの違和感を指摘された |
| スナップをどの画面でも外す | PC では違和感の指摘が無く、008 でユーザーが求めた「エンドロールで止まる」を残せる |
| 数字の待ち時間を短くするだけ（0.3→0.1秒） | 6割見えるまで待つ間の000は残る。待つ理由はリンクで通り過ぎる間だけなので、その間だけ待てば足りる |
| 暗記カードの下の段を2行分の高さで固定する | PC では案内が1行に収まり、1行ぶん余白が空く。案内の場所を取っておけば、どの幅でも表と裏で同じ高さになる |
| 優勝の札を枠の外へはみ出させてよいことにする | 見本の外の年表の文字に重なる |

### 影響範囲

- スマホでは、エンドロールの近くまで来ても自動で止まらない。エンドロールは画面いっぱい（100svh）のまま
- スナップを外して「ガクっ」と違和感が消えるかは、実機で確かめていない。この環境では指のスクロールと下のバーの出入りを再現できない
- 表紙の丸の大きさは小さい方の画面の高さ（svh）で決めているので、下のバーが消えても変わらない。エンドロールの置き直しも画面の高さが変わっても同じ位置になる。どちらも「ガクっ」の原因ではない

### 検証

- `npm run import`（見出し18件・ツール18件）、`npm run check` エラー0件、`npm run build` 成功
- `npm run check:contrast`: 幅1280・375・320px とも文字947か所の基準割れ0件、小さい押す所0件、横はみ出し無し
- 暗記カード: 幅320・375・1280px で、5枚とも表と裏でカードの高さが同じ。中身の高さは枠と同じで中のスクロール無し。「難しい」は左（translateX がマイナス）、「わかった」は右へ飛ぶ
- 得点板: 幅375・768・1280px で、優勝の札が枠の中に収まる
- 回る数字: スクロールで画面の上から84%の所まで来たとき回り始める。月の帯で10月へ飛ぶと、通り過ぎた数字は回らない。表紙のうごき帳へ飛ぶと、着いた先の2つだけ回る
- エンドロール: 「出演」と名前の間・役割と名前の間ともに10px
