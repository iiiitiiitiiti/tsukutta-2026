## 002. 月の節を色で塗った帯にする

- 日付: 2026-11-05
- 対象: `src/pages/index.astro`・`src/components/TimelineItem.astro`・`Counter.astro`・`src/styles/global.css`

### 決定

月の節を、その月の色で横いっぱいに塗った帯にする。帯の上の文字・線・丸は白（明るい4・7・8月は墨）にし、月の見出しは大きな数字で置く。全文は白い面にのせる。001 の「色を絞る」は取り消す。

### 背景

001（日付の強弱と色の絞り込み）を見たユーザーから「あんまり以前とデザインが変わっていない」「刷新してもいい」と言われた。ユーザーが最初に見せた参考画像には、色分けした横の帯や月ごとに色を変えた帯があった。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 001 の白地のまま細部を詰める | 変化が小さく、ユーザーに変わっていないと言われた |
| 4月の帯も白文字にする | 4月の橙 #ee6a3c と白の差は 3.11 で小さい文字が読みにくい。墨 #2a1206 なら 5.69 |

### 影響範囲

- 001 の日付の強弱（月の2件目からは日だけ小さく）はそのまま使う
- 全文の中の実物（Demo）とスクショの枠は白い面の中で今までどおり表示される

### 検証

PC 1280px と幅500px で撮り、帯・見出し・項目の重なりが無いことと、全文を開いたときに白い面で読めることを目で確かめた。`npm run check` 0件、`npm run build` 成功。
