## 017. フォーメーション帳を19件目として足す

- 日付: 2026-11-07
- 対象: 原稿 `note-articles/essay/今年つくったもの.md`・`src/data/extras.json`・`src/data/timeline.json`・`public/shots/formation.webp`

### 決定

- 11月6日に作ったフォーメーション帳を、11月の2件目として年表に足した。載せるツールは18件から19件になった（表紙の棒グラフ・エンドロールの「19こ作った」は件数から自動で出る）
- 原稿の項目は、フォーメーション帳の README と docs/DESIGN.md にある機能だけで書いた。「フラのステージで使う」はユーザーの言葉
- 「おわりに」の11月の文に、フラのステージの立ち位置を決めるアプリも作ったと1文足した。11月の作ったものを並べている段落なので、足さないと11月がかいものだけに読める
- アイコンは lucide の `users-round`（踊る人の並び）
- スクショは公開中のフォーメーション帳に、見本の作品（A〜F の6人・2場面・題「見本の作品」）を入れて編集画面を撮った。幅1280px で、下の空いた所を切って高さ530px にした。本物の作品は使っていない
- さわれる見本（`demo`）は作っていない

### 背景

ユーザーが「ダンスのフォーメーションのツールも載せて。フラのステージで使用するもの」と頼んだ（2026-11-07）。11-05 に「載せるツールは18件で確定」としていたが、そのあと作ったものなので足した。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| アイコンを `footprints`（足あと） | 立ち位置より歩く動きに見える。人の並びのほうがフォーメーションに近い |
| スクショを作品一覧の画面で撮る | 題と人数しか出ず、何をするツールか伝わらない |
| スクショをスマホの縦長で撮る | ほかの17枚と同じ幅1280px にそろえた |

### 検証

- `npm run import`（見出し19件・ツール19件・月6つ）、`npm run check` 0件、`npm run build` 成功
- `npm run check:contrast -- http://localhost:4330/tsukutta-2026/`: 幅1280・375・320px とも文字950か所の基準割れ0件
- ヘッドレス Chrome で撮った。表紙の11月の列にアイコンが2つ積まれ、数の札が2。年表の11月にかいものと並んで出て、「くわしく読む」を開くと本文とスクショが出る（幅1280・375）
