## 025. かけいぼを23件目として足す

- 日付: 2026-11-25
- 対象: 原稿 `note-articles/essay/今年つくったもの.md`・`src/data/extras.json`・`src/data/timeline.json`・`src/assets/fonts/`・`public/og.png`・`README.md`

### 決定

- 11月22日に作った家計簿アプリ「かけいぼ」を、11月の6件目として足した。載せるツールは23件になった。並びは作った日の順で、レシピ帳（11月20日）のあと
- 書く中身は本人が選択肢から選んだ（2026-11-25）
  - 一緒に使う相手は「複数人で使う」と書く。相手が誰かにも人数にも触れない（かいものと同じ書き方）
  - 作ったきっかけと使ってみた話は書かない。できることだけを書く（レシピ帳と同じ扱い）
  - 画像は「画像を準備中」の枠にする。撮るときは作り物の金額で撮り、本物の家計の金額は写さない。原稿の【画像】の行にもそう書いた
- 作った日は11月22日とした。かけいぼのリポの最初のコミットが 2026-11-22 21:06
- 機能の説明は、かけいぼのリポの設計メモ（`docs/DESIGN.md`）と画面の文言を読んで書いた（記録の画面・電卓・カテゴリ7つ・月の予算と残り・1日あたりの額・カテゴリごとの予算・カレンダー・「自分で払った」と「精算した」）
- 一緒に使う人へ渡すリンクのことは書いていない。リンクを知っている人が読み書きできる作りなので、仕組みを公開のページで説明しない
- アイコンは lucide の `wallet`（`piggy-bank` はがまんログが使っている）
- 新しい字が10字増えたのでページ専用のフォントを作り直した（849字）
- 表紙の11月の列が5つから6つになったので `public/og.png` を撮り直した（撮り方は決定018）
- README の件数を22件から23件に直した（2か所）
- 「おわりに」は変えていない。本人があとで文を調整すると言っているため

### 背景

2026-11-25 に数字を実物に合わせたとき（決定024）、11-22 に Mac で作られた家計簿アプリを足すかを本人に聞いた。「かけいぼを足す」と答えをもらった。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 「ふたりで使う」と書く | 本人が「複数人で使う」を選んだ。かいものと書き方がそろう |
| 人数に触れず「共通の財布の家計簿」とだけ書く | 本人が選ばなかった。同じ帳面を何人かで書くことがこのアプリの中心 |
| きっかけや使ってみた話を書く | 本人が「書かない」を選んだ。聞いていない話は作れない |
| 画像の枠を出さない（Worklog と同じ） | 本人が「準備中」を選んだ。作り物の金額の画面ならあとで撮って差し替えられる |
| 電波が弱くても書けることを書く | 設計メモに端末内の写しの話はあるが、電波の無い所で記録できるかを自分で試していない |
