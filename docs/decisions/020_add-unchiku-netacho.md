## 020. うんちくネタ帳を20件目として足す

- 日付: 2026-11-13
- 対象: 原稿 `note-articles/essay/今年つくったもの.md`・`src/data/extras.json`・`src/data/timeline.json`・`src/assets/fonts/`・`public/og.png`・`README.md`

### 決定

- 11月13日に作ったうんちくネタ帳を、11月の3件目として年表に足した。載せるツールは19件から20件になった（表紙の棒グラフ・エンドロールの出演は件数から自動で出る）
- 原稿の項目は、公開中のうんちくネタ帳の画面にある機能と、中身の件数（16件）だけで書いた。「クイズにしたあとも消さずにためていく」は作った窓口から聞いた作りの方針
- アイコンは lucide の `lightbulb`（電球）
- スクショは載せていない。「画像を準備中」の枠が出る。枠が出るツールは7つから8つになった
- 「おわりに」は変えていない。本人があとで文を調整すると言っているため
- 並びは作った日の順。旅行のしおり（11月10〜11日に作った。旅行のあとに足す予定）を足すときは、フォーメーション帳とうんちくネタ帳の間に入り、21件になる
- 新しい字が3つ（探・未・認）増えたのでページ専用のフォントを作り直した（815字）
- 表紙の11月の列が2つから3つになったので `public/og.png` を撮り直した（撮り方は決定018）

### 背景

ユーザーが「作ったもの棚、今年作ったもの年表に掲載してください」と頼んだ（2026-11-13。技術的な質問の窓口から年表の分を受けた）。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 実物の画面を撮って載せる | 中身の16件のうち6件は、ほかの人が作ったクイズの例を元にした問題文を持つ。ほかの人のクイズは載せない決まりなので撮らない。ほかの自分用ページ7つも準備中の枠のまま |
| `noShot` を付けて画像の枠ごと出さない | 枠を出さないのは仕事の中身が写る Worklog だけ。ほかの自分用ページと同じ扱いにそろえた |
| アイコンを `notebook-text`（帳面） | Worklog の `notebook-pen` と形が近く、表紙で見分けにくい |
| 数字を回す欄に「16件」を出す | 件数はこれから増える。ほかの回る数字（473施設・29,961枚など）と比べて小さく、見せ場にならない |
| 「おわりに」のクイズの道具の並びにネタ帳を足す | 本人が文を調整する予定なので触らない |

### 検証

- `npm run import`（見出し20件・ツール20件・月6つ）、`npm run check` 0件、`npm run build` 成功（フォントの字の検査も通る）
- ヘッドレス Chrome で撮った。表紙の11月の列にアイコンが3つ積まれ、数の札が3。年表の最後にうんちくネタ帳が出て、「くわしく読む」を開くと本文と準備中の枠が出る（幅1280・375）。エンドロールの出演の最後がうんちくネタ帳
- `npm run check:contrast -- http://localhost:4330/tsukutta-2026/`: 幅1280・375・320px とも文字971か所の基準割れ0件
