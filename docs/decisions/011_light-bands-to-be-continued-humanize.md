## 011. 年表の帯を明るく薄くし、終わりに「つづく」を置いて12月に備え、原稿に humanizer-ja を通し、エンドロールを速める

- 日付: 2026-11-06
- 対象: `src/styles/global.css`・`src/pages/index.astro`・`src/components/HeroShelf.astro`・`MonthBar.astro`・`Finale.astro`・`scripts/check-contrast.mjs`・`src/data/extras.json`・原稿 `note-articles/essay/今年つくったもの.md`

### 決定

- 帯の色: 帯の地だけ明るく薄い色（`--bN`）にした。月の色の色相のまま、oklch の明るさを0.91、鮮やかさを今の6割にした。表紙の丸と上の色帯は今の `--mN` のまま
- 年表の終わり: 最後の月の線の続きを点線で下へ伸ばし、薄れて消える。途中に次の月の数字を輪郭だけで置き、「12月へつづく」と添える。画面に入ると点線が上から引かれ、数字と添え書きが浮かぶ（1回だけ）。最後の月が12月になったら「2027」「来年へつづく」に替わる
- 12月への備え: 表紙の棚と上の色帯の月の範囲を「4月から、11月か最後の月まで」にした。12月の色（`--m12` #8dcef4・帯 `--b12` #c2e8ff・`--ci` #005d89）を足した。原稿に「## 12月」の節を足して取り込めば、表紙・上の色帯・年表に12月が出る。表紙の丸は、列が幅に収まらないとき列の幅に合わせて小さくなる（幅320pxで9列なら約28px。8列なら31.5px、幅375px以上は今までどおり34px・60px）
- 原稿: humanizer-ja を通した（下の「原稿の直し」）
- エンドロール: 流れる速さを1秒に90pxから120pxにした
- 検査スクリプト: 塗りが透明で輪郭だけの文字は、輪郭の色で差を測る

### 背景

### 原稿の直し

suiko（low_burstiness 1件・長い連体修飾1件）と yomiyasu_lint（間を作る読点5件・英字の前後の空白1件）の指摘と、20のルールで全文を読んだ結果で直した。

- 短い主題のあとの間を作る読点を外した（「8月19日には、」「約3万問は、」「「ひとつめ」は、」など）。「月ごとの振り返りでは、」は場面の枠なので残した。冒頭の「10月に、自分が作ったものを」は外すと「10月に作ったものだけ」と読めるので残した（別モデルのレビューで指摘）。「9月19日に、前の日に作った」は「に」が続くので「9月19日、」にした
- 英字の前後の半角空白を外した（Mac と Windows・QUIZ ATLAS・Aʻo Hawaiʻi）。「今」と「いま」を「いま」にそろえた（「今やること」は画面の文言なので残した）
- うごき帳の長い連体修飾（34字）を「〜動き、〜動き、〜動きなど」に分けた
- つくったもの棚の節と「おわりに」の冒頭で、はじめにの文を繰り返していた所を消した
- 「並べてみて気づいたのは〜ことだ」を「並べてみると〜になっていた」にした
- 締めの問いかけ「来年の今ごろ、この年表にはどんな続きが並ぶだろう。」を「いまも作り続けている。この年表にも、これから続きが並んでいく。」にした。ユーザーがこれからも作り続けると言ったため。推量を言い切りに変えた所はここだけ
- 数字・日付・固有名詞は変えていない。suiko の low_burstiness は残した（随筆の調子で、短い文はすでに混ざっている）

ページだけにある一言の説明（`extras.json` の lead）も同じ検査に通し、指摘0件。「今は Aʻo Hawaiʻi の一部」だけ原稿にそろえた。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 月の色（`--mN`）ごと明るく薄くする | 表紙の棒グラフの丸が白地に溶ける。依頼は帯のグラデーションの色 |
| 004 で却下したパステル A に戻す | 色相が今の配色と違う。今の色相のまま明るさと鮮やかさだけ変えれば、月の色の見分けは保てる |
| 年表の終わりに空の12月の帯を置く | 作ったものが無い月を帯にすると、5・6月の「作ったものは無し」と同じに見える |
| 終わりの印を点滅させ続ける | 5秒を超えて自動で動き続けるものは止める手段が要る（WCAG 2.2.2）。1回だけ引く形にした |
| 12月を表紙と上の色帯に今から出す | まだ作ったものが無い。12月の節ができた時点で出るようにした |

### 影響範囲

- 004 の「帯の色」は、帯の地については `--bN` に替わった。表紙の丸と上の色帯は 004 の色のまま
- 帯と白い面（スクショの丸・開いた全文）の差は1.3前後になった。004 でパステルを退けた理由の1つだが、今は浮かせる物に影がある（009）
- 12月の節を足すと、11月の帯は12月の色へ移り、最後の月（12月）が白へ移る
