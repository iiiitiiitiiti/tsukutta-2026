## 016. エンドロールを途中の高さ変更でも置き直し、スクリプトが止まったら中身を出し、かいものの「消す」の枠線を白にする

- 日付: 2026-11-07
- 対象: `src/components/Finale.astro`・`TimelineItem.astro`・`demos/Kaimono.astro`・`src/pages/index.astro`

### 決定

- エンドロール: 流している途中や止めている間に枠の大きさが変わったら、経った時間を保ったまま測り直して流し直す。止めていたなら止めたまま置く。枠の大きさが変わらない resize（スマホの下のバーの出入りなど）では何もしない
  - 前は流し終えた後だけ置き直していた。途中で高さが変わると、締めの札が古い高さの真ん中で止まった
- スクリプトが止まったとき: ページの頭に見張りを置いた。読み込みが終わった時点で準備の印が無ければ、隠したままにせず出す
  - 年表の項目・月の見出し・「つづく」は、現れる動きの印（`ok-reveal`）が無ければ全部に `is-in` を付けて出す
  - エンドロールは、準備の印（`ok-roll`）が無ければ `html` に `roll-static` を付けて、スクリプトが動かないときと同じ並べた形にする。途中で入った位置の指定も消す
  - 前は `html` の `.js` を最初に付けるので、後のスクリプトが途中で止まると、項目が透明のまま、エンドロールは黒い枠だけになった
- かいものの見本: 「消す」ボタンのフォーカスの枠線を緑から白にし、内側へ6px入れた。赤の地との差は緑で約1.3:1、白で5.44:1

### 背景

ユーザーの依頼で、11-06 の変更（310635c〜c6b5005）を Codex にレビューしてもらった。8件の指摘のうち、コードで確かめて直す価値があった3件を、ユーザーの「3件とも直す」で直した。

### 見送った指摘

| 指摘 | 見送った理由 |
|---|---|
| 暗記カードで全部「わかった」にすると定着率が0% | 本物と同じ計算（ts-fsrs の既定）。「わかった」は10分後にもう一度出す扱いで、定着に入るのは「簡単」だけ |
| かいもので、チェックの0.32秒の間に消して取り消すと食い違う | ふつうの操作では起きにくい |
| 数字が回り始めるまでの1.5秒の保険が、滑る途中で切れることがある | `scrollend` に対応していない古いブラウザだけ |
| 前後リンクの URL の形を確かめていない／データを script に埋め込む形 | データは自分で書く `advent.json` と固定の問題だけ |
| 部品ごとのイベントの片付けが無い | 1ページだけの静的なサイトで、ページを移らない |

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 流している途中の高さ変更では一度止めて、次に流すときに測り直す | 止める操作をしていないのに止まる |
| `.js` をやめ、準備が済んでから隠す印を付ける | スクリプトが動くまでの一瞬、項目が出てから消えて現れ直す |
| 見張りで失敗を見つけたら `.js` ごと外す | 「くわしく読む」の開閉はスクリプトが動いていても、スクリプトが無いときの見た目の指定と重なって文言がずれる |

### 検証

- `npm run check:contrast -- http://localhost:4330/tsukutta-2026/`: 幅1280・375・320px とも文字937か所の基準割れ0件
- ヘッドレス Chrome（幅1280）
  - 流して4秒の所で高さを800→600pxにすると、経過は続き、流し終えたとき締めの札の真ん中が枠の真ん中（300px）に来る。止めていた場合も止めたまま（経過3983ms・「続きを流す」）で、続きを流すと真ん中で止まる
  - `IntersectionObserver` を消してスクリプトを途中で止めると、`html` は `js roll-static` になり、隠れた項目0件、札の不透明度1、エンドロールは並べた形（position static・題の札の不透明度1）
