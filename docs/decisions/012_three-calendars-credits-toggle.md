## 012. アドベントカレンダー3企画の前後を並べ、表紙に企画の一言を置き、エンドロールを映画のクレジットに増やし、開閉の文言を押した瞬間に替える

- 日付: 2026-11-06
- 対象: `src/data/advent.json`・`src/components/AdventNav.astro`・`src/pages/index.astro`・`src/styles/global.css`・`src/components/Finale.astro`・`src/components/TimelineItem.astro`

### 決定

- 表紙: 題の下に「この記事は（企画名）の22日目です。」を置く。企画名は企画のページへのリンク
- 前後リンク: 同時に開いている3企画（壁達の福音：序・破・Q）を並べる。この記事の企画の Q を先頭に「この記事の企画」の印を付け、前の日（12/21）と次の日（12/23）。序と破は前の日・同じ日（12/22）・次の日。札は3つの状態を持つ
  - 担当者・題・リンクがそろうと押せる札
  - 担当者だけなら「準備中」と担当者名
  - 担当者がいなければ「まだ空いている日」
- `advent.json` の形を `{ day, calendars: [{ name, url, mine, entries: [{ date, author, title, url }] }] }` に変えた。前の日・同じ日・次の日の別は `day` との日付の差で決める
- エンドロール
  - 作った物を「出演」として流す
  - そのあと、スタッフ（監督・主演・注文・制作・記録・書体・アイコン）、スペシャルサンクス、製作（Q の企画の制作委員会）を1つずつ真ん中に積んで流す
  - 出演欄（日付と名前の2列）は、溝を画面の真ん中に置くのをやめた。外枠の真ん中と、行ごとの真ん中の平均との中間に置く。スクリプトで横位置を測って合わせる
- 「くわしく読む」と「閉じる」: 文言・矢印・下線を押した瞬間に切り替え、新しい文言を下から浮かばせる。前は閉じる動きが終わるまで「閉じる」のまま残り、終わった瞬間に文言と矢印が飛んでいた

### 背景

ユーザーの指摘（2026-11-06・8回目）。

- アドベントカレンダー企画であることを一言書く
- 開閉の切り替えが滑らかでない
- エンドロールの「今年つくったもの」と各ツールが真ん中に見えない。数値ではなく目で見て合わせる。クレジットをもっと大げさに増やす（制作委員会など）
- 同時に走っている3企画すべての前の日と次の日を載せる。ほかの2企画は同じ日も載せる

ユーザーは途中で、破の12/22にも誤って登録していたと言い、「Q だけだと思ってください」と指示した。破の12/22は空きとして扱う。担当者は adventar の3企画のページ（2026-11-06 13時ごろ）から写した。題とリンクはまだ無い。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 出演欄の溝を画面の真ん中に置く（前の形） | 日付が短く名前が長いので、塊が右に寄って見えるとユーザーに言われた |
| 出演欄の外枠を真ん中に置く | 一番長い名前（ビジュアルクイズのスライド）に引っぱられ、大半の行が左に寄って見えた。行の右端の平均は外枠の右端より約130px内側 |
| 出演欄を1行ずつ真ん中に寄せる | 日付の縦の並びがそろわず、映画の2列の字幕に見えなくなる |
| クレジットに骨組みや公開先（Astro・GitHub Pages）を足す | 画面に作り手側の道具の名前を出さない決まり（規律14）。書体とアイコンは使わせてもらった物の表示として残した |
| クレジットに撮影・照明などの役を足す | 作っていない役になる。作り話を書かない決まり。大げさにするのは、本当にいた人と物の呼び方と並べ方にとどめた |
| 担当者が決まっただけの日に、adventar の一言（「〜のおはなし（したい）」など）を題の代わりに出す | 記事の題ではない。題とリンクがそろうまで「準備中」にする |

### 影響範囲

- ページに URL を載せない決まりの例外を、アドベントカレンダーの記事と企画のページへのリンクに広げた
- 12月に各記事が公開されたら、`advent.json` の title と url を埋める。破の12/22は、ユーザーが登録を取り消したあと別の人が入れば埋める
- エンドロールの長さが増えた（行が18件から、スタッフ5件・サンクス5件・製作1件ぶん）
