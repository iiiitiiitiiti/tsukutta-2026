## 015. ツールの画面は、人の情報と他人の作ったものが写らない画面で撮る

- 日付: 2026-11-06
- 対象: `public/shots/<id>.webp`（10枚）

### 決定

- 幅1280px・高さ800pxの画面で撮り、WebP（品質82）にした。余白が多い画面と、下に他人の物が出る画面は上から切った
- 公開中のツールはそのまま撮った（Aʻo Hawaiʻi・がまんログ・うごき帳・暗記カードのデッキ一覧）
- 本物のデータを出すと家族や仕事の情報が写るツールは、手元で見本を流して撮った
  - かいもの: 品物6つの見本リスト（Aさん・Bさん）。本物の鍵と家の買い物リストは使わない
  - 動物園・水族館ログ: ログインと記録を見本に差し替え、記録は空のまま。施設一覧は本物
  - ひとつめ: 予定は空、使用量はその時の値。ニュース・作問の種・note・Wikipedia の段は切り落とした
- クイズ得点板: 参加者 A〜D さんを足し、5○2✕ のルールで途中まで点を付けた
- disney-archive: 人物名鑑の見出しから人数までで切った。人物の写真と公式ブログの写真は写さない
- ビジュアルクイズのスライド: 手元の元ファイルと見本の回で、写真を使わない「あるなし」の問題を出した。見本の鳥の写真は CC BY-SA で表記が要るため避けた

### 背景

ユーザーが「非公開分も全部撮ってください」と頼んだ（2026-11-06）。17枚のうち claude.ai の Artifact 7つ（楽器のはじめかた・いきもの手帳・問題集の下ごしらえ・QUIZ ATLAS・作問レビュー・問い読み・つくったもの棚）は、ログインが要るためこの回では撮れていない。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 本物のデータのまま撮る | かいものは家の買い物リスト、動物園ログは家族の記録、ひとつめは仕事の予定が写る |
| ログイン画面・鍵の入力画面を撮る | 何をするツールか伝わらない。かいものの入口は古い題（ふたりの買い物リスト）のまま |
| ひとつめを係につながらない状態で撮る | 「つながりません」の帯が出て、壊れた画面に見える |
| 暗記カードの学習画面を撮る | カードの問題文は他人が作ったクイズ |

### 影響範囲

- かいもの・得点板・ビジュアルクイズの画面の中身は見本で、本当の使用記録ではない
- 見本を流すための設定は scratchpad に置き、各ツールのリポジトリには何も足していない
- 画像の差し替えは `public/shots/<id>.webp` を置き換えるだけで済む

### 検証

- `npm run check` エラー0件、`npm run build` 成功
- `npm run check:contrast`: 幅1280・375・320px とも文字937か所の基準割れ0件
- 動物園ログの1枚を開いて表示の幅を測った（画面の幅1280pxなら496px、375pxなら271px）
