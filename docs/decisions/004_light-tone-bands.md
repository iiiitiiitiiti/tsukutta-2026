## 004. 月の帯をライトトーンにして、帯の上の文字を全部の月で黒にする

- 日付: 2026-11-05
- 対象: `src/styles/global.css`・`src/components/MonthBar.astro`

### 決定

月の帯の色をライトトーンにし、帯の上の文字・線・丸を全部の月で黒（`--ink` #1c2433）にする。アイコンや上の色帯の今の月の文字など、白地に置く色（`--ci`）は今までの濃い色のまま残す。

| 月 | 帯（`--c`） | 黒い文字との差 | 白地の文字・アイコン（`--ci`） |
|---|---|---|---|
| 4月 | #f7a985 | 8.13 | #bf4518 |
| 7月 | #a9d39b | 9.25 | #3d7a65 |
| 8月 | #f6cf5c | 10.37 | #946600 |
| 9月 | #86cdc6 | 8.57 | #136170 |
| 10月 | #a7b8ec | 7.94 | #2f4b8f |
| 11月 | #c3c5cc | 9.02 | #3c3f45 |

帯の色が淡くなったので、上の固定した色帯の今の月以外の薄め具合を opacity 0.45 から 0.7 にした。

### 背景

003 で全部の月を濃い色＋白文字にそろえたところ、ユーザーから「色がドス黒い」と言われた。黒い文字が読める明るさの色にしたいという指示だった。パステル（A）とライトトーン（B）の見本を本物のページに色を差し込んで撮り、ユーザーが B を選んだ。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| A パステル（4月 #fbd5c3 など、黒との差11以上） | 月どうしの色の差が小さく、「くわしく読む」の白い面と帯の境目も弱い（白との差1.3前後）。ユーザーは B を選んだ |
| 003 の濃い色＋白文字のまま | ユーザーに「ドス黒い」と言われた |

### 影響範囲

- 003 の「帯の上の文字を全部の月で白」は取りやめ。003 の opacity をやめる決まり・空の月の文字色・得点板と暗記カードの読み上げは残る
- 文字色をそろえる方針（全部の月で同じ色）は 003 から引き継ぎ、白から黒に変えた

### 検証

- Lighthouse のアクセシビリティ: PC・スマホとも100点
- 全文をすべて開いた状態で、文字705か所の差を幅1280・375・320pxで計算し、基準を割るもの0件
- `npm run check` 0件、`npm run build` 成功。幅1280pxと375px（全文を開いた4月）と上の色帯を撮って目で確かめた
