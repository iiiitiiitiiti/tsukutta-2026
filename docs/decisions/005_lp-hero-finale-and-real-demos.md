## 005. 表紙を積み上がる棒グラフ、締めを本物の得点板にし、さわれる見本3件を本物の写しに作り直す

- 日付: 2026-11-06
- 対象: `src/components/HeroShelf.astro`・`Finale.astro`・`demos/Scoreboard.astro`・`demos/Flashcards.astro`・`demos/Kaimono.astro`・`Demo.astro`・`src/lib/confetti.ts`・`src/pages/index.astro`・`src/styles/global.css`・`scripts/check-contrast.mjs`

### 決定

- 表紙: 作った18件のアイコンが作った順に上から落ち、月の列に積み上がる。積んだ高さがそのまま月ごとの作った数の棒グラフになる。アイコンは年表のその項目へ、月の数字はその月の帯へのリンクで、目次を兼ねる。PC では左に年・題・序文、右にグラフを置いて最初の画面に収める
- 題は「今年つくったものを／年表にした」で折り返す。原稿の題を「を」の後ろで2つの塊に分けて出す（原稿に「を」が無ければ1つの塊のまま）
- 締め: おわりにの後に、本物のクイズ得点板の解答者カード（自由得点）で「2026年 18」を出す。±1 で数が動き、トロフィーで本物と同じ WINNER 画面と紙吹雪が開く
- さわれる見本3件（得点板・暗記カード・かいもの）は、本物のコードから色・大きさ・角の丸み・動きの時間・文言・決まりごとを写した小型版にする
  - 得点板: m○n× の解答者カード3枚。ロック・優勝の札・得点順の並べ替え（350ms の FLIP）・枠の中の WINNER 画面
  - 暗記カード: 学習画面（← と進み具合の棒・めくれるカード・「難しい／わかった」・左右のスワイプ・結果の半円ゲージ）。次回の間隔は本物の計算（ts-fsrs の既定）で出した値
  - かいもの: 上の帯・お店ごとのリスト・丸いチェック（320ms で購入済みへ）・購入済みの折りたたみ・下の足す欄（品名からお店を当てる語の表は本物のまま）・重複の知らせ・左になぞって消す・取り消しのトースト
- 紙吹雪は canvas-confetti を入れず、本物が撃つ5発と同じ飛び方を `src/lib/confetti.ts` に小さく書いた

見本に入れなかったもの: 得点板のプレイヤーの追加・削除・名前の編集・ルールの切り替え、暗記カードのデッキ選び・カードの編集、かいもののメニュー・品物を直すシート・ほかの人との共有。

スマホの年表の中は本物の画面より狭いので、得点板は枠が330px 以下なら1列にし、見本の外枠の余白を詰めて本文の余白へはみ出させた。

### キーボードと本物どおりの割り切り

- 暗記カードの「もう一度」「簡単」は本物と同じく、なぞる操作だけで出す。評価そのものは「難しい」「わかった」のボタンでできるので、キーボードでも学習を最後まで進められる
- 得点板は本物と同じく、得点順の間はカードのアイコンと○✕を隠す

### 最終レビューで直した所

別のモデル（fable-advisor）に差分を読んでもらい、本物のコードで裏を取って次を直した。

- かいものは状態が変わるたびに一覧を全部作り直していたので、チェックの丸・行の縮み・なぞった行の戻りが動かず、逆に全部の行の出てくる動きが毎回走っていた。今ある行に印を付けて動かし、出てくる動きは新しく出た行と売り場だけにした
- かいもので消した後に足した品が、消した品の取り消しで消えていた。足した品を残して戻すようにした
- かいもので開いた行を押すと、閉じるのと同時にチェックも入っていた
- 暗記カードは答えを出す前のなぞりで評価が決まっていた（本物はめくった後だけ）
- 得点板の WINNER 画面で Shift+Tab が覆いの下へ抜けていた。締めと同じく2つのボタンの間で折り返す
- 得点板の失格のカードを、ロック中と同じ灰色にした（本物は半透明）

### 背景

ユーザーから「ツールのサンプルが本物と違いすぎて全く参考にならない」「アドカレ企画なので面白みが欲しい」と言われた。見本は「本物を写した小型版」を選び、面白みは「もっと LP として全力でデザインしてみて」と頼まれた。表紙と締めの見本を撮って見せ、ユーザーが「この方向で進めて」と決めた。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 本物を iframe で埋め込む | 本物は保存先（Firestore・IndexedDB）や画面いっぱいの作りが前提で、年表の中の小さな枠では動きが崩れる。かいものは共有の鍵が要る |
| 本物を操作した動画 | さわれない。今までの「さわってみる」より後退する |
| 表紙の左に巨大な月の数字を固定して流す | 上の月の色帯と役割が重なる |
| 表紙に作ったものの名前を流れる帯で並べる | 名前は読み取れず、数の偏り（4〜9月が少なく10月に8件）が伝わらない |
| 月ごとのポスター（B案） | 18件を1枚ずつ見せると長くなり、表紙で全体が見えない |

### 影響範囲

- 002 の「表紙は年表と同じく中央にそろえる」は PC では取りやめ。スマホは中央のまま
- `scripts/check-contrast.mjs` は全文を開いてから1.5秒待って測る。見本の出だしの動き（透明から始まる）を測ると誤って基準割れに数えるため。透明で見えていない文字（さわったときだけ出る吹き出し）と、読み上げ専用の見えないラベルは数えない
- かいものの数量・メモの文字のクラス名は `.memo` にした。`.note` はページの自己紹介の節で使っていて、余白がかかって行が高くなった
