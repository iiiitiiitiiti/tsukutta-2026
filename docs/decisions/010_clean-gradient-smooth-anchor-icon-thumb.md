## 010. 帯のグラデーションを oklch で混ぜて11月を桃色にし、ページ内リンクを滑らせ、丸い小窓をアイコンに固定する

- 日付: 2026-11-06
- 対象: `src/styles/global.css`・`src/pages/index.astro`・`src/components/Shot.astro`・`src/components/Counter.astro`

### 決定

- 帯のグラデーション: 色の混ぜ方を oklab から oklch に変えた。最後の11月だけは白へ移すので oklab のまま
- 11月の色: 灰 #c3c5cc を桃 #e8b0d5 に替えた。白地の文字・アイコンの色（`--ci`）は #3c3f45 から #82326c にした。004 の「11月 灰」の差し替え。ユーザーが「配色を変えても問題ない」と言った
- ページ内リンク: `html` に `scroll-behavior: smooth` を付けた。月の帯・表紙のアイコン・上に戻るボタンで、飛ばずに滑って移る
- 回る数字: 画面に入ってから0.3秒とどまって見えていたら回す。滑って通り過ぎる間に回し終えてしまい、戻って見たときに止まった数字になっていた（別モデルのレビューで指摘。表紙から11月へ滑ると6つすべてが回り終えていた）
- 年表の丸い小窓: スクショがあっても常にアイコンを出す。全文の中の大きなスクショは今までどおり写真に替わる

### 背景

ユーザーが公開中のページを見て指摘した（2026-11-06・6回目）。

- アンカーリンクにもアニメーションを付ける
- グラデーションの濁りを無くす。参考は photoshopvip.net の記事（補色や90度以上離れた色を直線でつなぐと中間が灰色にくすむ。間に色を足すか、色相環に沿って混ぜる）
- 丸い小窓はアイコンのままでよい

oklab で混ぜた中間の鮮やかさ（oklch の C）を計算すると、4月→7月が 0.067（両端は 0.105 と 0.088）、8月→9月が 0.075（両端 0.139 と 0.072）に落ち、ベージュやカーキになっていた。oklch で混ぜると 0.097 と 0.105 で、間に黄や若緑が入る。10月→11月は11月が灰（C 0.010）で、どう混ぜても色が抜けていた。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 隣り合う月の間に手で中間色の止まりを足す（記事の手法そのまま） | oklch で混ぜると同じ効果が計算で出る。月の色を替えたときに止まりを直す手間も無い |
| 11月を灰のまま、10月→11月だけ止まりを足す | 終わりの色が灰なので、どこかで色が抜ける。表紙の棒グラフでも、作ったものが無い月（5・6月）の灰と見分けにくかった |
| 11月を薄紫（#e1b2e3） | 10月の藤青と近く、帯の境目が分かりにくい |
| 最後の月も oklch で白へ移す | 白には色相が無く、途中に薄い紫が出た。撮って確かめた |

### 影響範囲

- 004 の色の表のうち11月の行は、この決定で差し替えた
- 古いブラウザは `in oklch` を読まず、普通の混ぜ方のグラデーションになる
- `scroll-behavior: smooth` はスクリプトの `scrollTo` にも効く。撮影スクリプトで位置を飛ばすときは `behavior: 'instant'` を付ける
- `public/shots/` にスクショを置いても、年表の丸い小窓は写真にならない

### 検証

- `npm run check` 0件、`npm run build` 成功
- `npm run check:contrast -- http://localhost:4330/tsukutta-2026/`: 幅1280・375・320px とも文字894か所の基準割れ0件
- 帯の文字色 #1c2433 と oklch の混ぜ色の差は全区間で最小 7.94:1（10月の色そのもの）。11月の帯との差 8.60、`--ci` #82326c と白の差 8.01
- ヘッドレス Chrome で撮った（幅1280・375）。4月→7月・8月→9月・10月→11月・11月→白の境目を、前の色と並べて比べた
- 表紙の棚から11月の項目へ滑ったあと、回った数字は0個。10月の数字の前で1秒止まると回る。表紙に戻って4月の数字の前で止まっても回る
