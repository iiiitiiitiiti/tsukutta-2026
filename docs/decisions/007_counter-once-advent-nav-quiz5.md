## 007. 数字は一度だけ回し、アドカレの前後リンクの枠を置き、暗記カードを指定の5問にする

- 日付: 2026-11-06
- 対象: `src/components/Counter.astro`・`AdventNav.astro`（新規）・`src/data/advent.json`（新規）・`HeroShelf.astro`・`Finale.astro`・`demos/Flashcards.astro`・`src/data/extras.json`・原稿 `note-articles/essay/今年つくったもの.md`

### 決定

- 回る数字: 最初に画面へ入ったときだけ回す。画面の外へ出て戻っても止まった数字のまま。前は外へ出ると巻き戻し、入るたびに回り直していた
- アドベントカレンダーの前後の記事: 締めのエンドロールの下に「前の日 12.21」「次の日 12.23」の2枚の札を置く。担当者・題・リンクは `src/data/advent.json` に書く。どれかが空のうちは押せない破線の札で「準備中」と出す
  - ページに URL を載せない決まりの例外。ユーザーが置くと決めた
- 表紙: 指したアイコンの列（`.chart__slot`）を一番上に重ね、枠の輪が上や隣のアイコンに隠れないようにした
- 暗記カードの見本: 問題をユーザーが選んだ5問に替えた（006 の「問題集の欄が自作の3問」は取りやめ）。見本の幅が360px以下のときは問題文を16pxにする。本物はスマホの画面の幅いっぱいを使う。見本は年表の札の中にあって幅が約240pxしかなく、長い問題文が半分しか見えなかった
- 締め: クレジットの「企画・注文」を「がーさん」にした（006 の「わたし」を差し替え）。流れ始めを早くした。枠が15%見えたら流し始め、見出しが枠の下から3割ほどの所から動き出す。出だしの加速もゆるめをやめた
- 数え直し: ガチャ 15,639語・いきもの手帳 369種に直した（ページの回る数字と原稿の両方）。棚は23件で原稿の「20件を超えている」のまま
- 原稿: QUIZ ATLAS の名前の由来（Codex のモデル Astra にちなむ。新しいモデルの力を確かめる意味もあった）を足した。いきもの手帳は「10日ほどで285種」「11月6日の時点で369種」に直した

### 背景

ユーザーが公開中のページを見て指摘した（2026-11-06・3回目）。原稿もこの窓口の担当になった。

- 数字が画面に入るたびに回り直す
- 表紙で指したときの枠が、ほかの丸と重なって見切れる
- 締めの流れ始めまでが長い
- アドカレの前後の記事へのリンクを置くので用意しておく（担当者・題・リンク）

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 前後リンクを表紙の上へも置く | ユーザーの指定は「ページのどこか」で1か所。読み終えた所で次へ進むのが自然なので末尾だけにした。上にも要るなら同じ部品を置けば済む |
| 中身が空の前後リンクは出さない | 公開前に置き場所と見た目を確かめられない。空でも枠が出るほうが、中身を書いたときの見え方が分かる |
| 暗記カードの字を常に小さくする | PC の幅では本物と同じ20pxで収まる。狭いときだけ替えれば本物から離れない |
| 締めを最初から見出しが枠の真ん中にある状態で始める | 下から流れてくるエンドロールらしさが無くなる。下から3割の所なら待たずに動きも見える |

### 影響範囲

- いきもの手帳の369種は、db の文書500件からネタ帳54件・コラム64件・子ページ（品種など）13件を引いた値。species を全件読んで数えてはいない。db に他のコレクションがあれば少なくなる。記録との突き合わせ（10-30 に285種、11-02 に27種、11-04 に57種と親ページ1件を追加）とは1種の差で合う
- 原稿の「10月末の時点で168種」は誤りだった。168種は10月26日の数で、10月29日には293件になっていた
- QUIZ ATLAS の由来のモデル名は、ユーザーの言葉は「atras」。記録（claude-memory の episodes.md）では Codex のモデルは GPT-6-Astra なので Astra と書いた。記録では Astra で作ったのは9月9日の作り直しで、9月5日の最初の版ではない
