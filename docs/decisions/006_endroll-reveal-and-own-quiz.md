## 006. 締めをエンドロールにし、年表をスクロールで現し、暗記カードを自作のクイズにする

- 日付: 2026-11-06
- 対象: `src/components/Finale.astro`・`HeroShelf.astro`・`TimelineItem.astro`・`demos/Scoreboard.astro`・`demos/Flashcards.astro`・`src/pages/index.astro`・`src/styles/global.css`・`src/data/extras.json`・`scripts/check-contrast.mjs`・原稿 `note-articles/essay/今年つくったもの.md`

### 決定

- 締め: 005 の得点板カード（「2026年 18」を ±1 できる）をやめ、エンドロールにした。作った物を日付順に流し、クレジット（企画・注文 わたし／制作 Claude／書体／アイコン）を経て「2026 18こ作った おわり」で止まる
  - 枠が4割ほど見えたら自動で流し始める。止める・続きを流す・もう一度流すのボタンを付けた（5秒を超えて自動で動くものは止められるようにする。WCAG 2.2.2）
  - スクリプトが動かないときは、流さずに全部を並べて見せる
- 表紙: 指したアイコンの名前を吹き出しで横に出すのをやめ、グラフ左上の空いた所に日付と名前を出す。落ちてくるアイコンは題と序文の後ろを通す
- 年表: 項目と月の見出しは、スクロールで画面に入ると下から現れる。「くわしく読む」は高さが伸び縮みし、開くときは中身が上から順に浮かぶ。動きを減らす設定でも動かす（ユーザーの方針）
- 自己紹介とおわりにの幅を960px にした（表紙と年表は1200px のまま）
- 得点板の見本: ○と✕の得点を縦に積んだ。横に並べると見本のカードの幅いっぱいになり、枠からはみ出して見えた
- 暗記カードの見本: 問題を、手元のクイズのうち問題集の欄が「自作」の3問に替えた（前は年表の中身で作った3問）。補足は本物と同じく「別解・正誤判定基準・補足」の欄を出し、空なら出さない
- 原稿: 10月19日の3件を別々の見出しにした。Worklog の機能は「- 語：説明」で書き、ページでは定義リストで出す

### 背景

ユーザーが公開中のページを見て、まとめて指摘した（2026-11-06）。

- 表紙の吹き出しが隣の列のアイコンに隠れて読めず、一番下のアイコンでは棒にかぶる。落ちるアイコンが文字を隠す
- 締めは「数が増えたり減らせたりするのは意味が伝わりにくい。わざわざ作ったツールを使わなくてよい」。最後にエンドロール的に「制作 Claude」などを書く
- 暗記カードの問題は年表のクイズではなく、自作の実際のクイズにする

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 締めをスクロールに合わせて流す（読む人のスクロールで字幕が動く） | 止める操作が要らない利点はあるが、字幕の速さが読む人まかせになり、エンドロールに見えにくい。流れ終わるまで長いスクロールの空白ができる |
| 締めを止めずに流し続ける | 5秒を超えて自動で動くものに止める手段が無いと WCAG 2.2.2（A）を満たさない |
| 表紙の吹き出しを前面に出すだけ（重なり順の修正） | 前面に出しても隣の列のアイコンを覆う。一番下のアイコンでは棒にかぶる問題が残る |
| 表紙の吹き出しをアイコンの上に出す | 同じ列の上のアイコンを覆う。8件積む10月の列では必ず重なる |
| 開閉の動きを `::details-content` の CSS だけで付ける（005 まで） | 対応していないブラウザではすぐ開いて動かない。閉じるときも動かない |
| 暗記カードに手元の約3万問から選ぶ | ほとんどはほかの人や団体の問題で、他人のクイズを載せない決まりに反する |

### 影響範囲

- 締めの印は `data-endroll` にした。最初に `data-roll` と付けたら、回る数字（`Counter.astro`）の印と同じで、締めのスクリプトが数字の部品をつかんで止まった
- `scripts/check-contrast.mjs` は測る前にスクロールで現れる要素を全部出す。画面の外の項目は透明なままで、測らずに飛ばしてしまうため
- 005 の「締めの得点板」「WINNER の開閉」は取りやめ。紙吹雪（`src/lib/confetti.ts`）は得点板の見本で使い続ける
- クレジットの「わたし」は本文の一人称に合わせた。作者の呼び名を出すなら差し替える

### 最終レビューで直した所

別のモデル（fable-advisor）に差分を読んでもらい、次を直した。

- 原稿で、楽器のはじめかたを Aʻo Hawaiʻi へまとめた日（9月19日）が、Aʻo Hawaiʻi の見出し（9月18日）と食い違って読めた。「前の日に作った Aʻo Hawaiʻi へ」と書いた
- 原稿のうち根拠を確かめきれない書き足しを戻した。QUIZ ATLAS の名前の由来（記録が無いのでユーザーに聞く）、ビジュアルクイズのスライドを作った理由の言い足し（ユーザーの言葉どおりにした）、いきもの手帳の168種になった時期
- 締めを流し終えた後に画面の高さが変わると、「おわり」の塊が枠の真ん中から外れていた。置き直す
- 開閉の動きの中の overflow は古いブラウザで無視されるので、動いている間だけ要素に付ける
- 表紙のアイコンをマウスで押すと、飛んだ後も左上に名前が残っていた。キーボードで選んだときだけ出す
