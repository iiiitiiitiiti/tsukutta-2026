## 009. 年表の帯を次の月の色へ移るグラデーションにし、AI っぽい型を減らす

- 日付: 2026-11-06
- 対象: `src/pages/index.astro`・`src/styles/global.css`・`src/components/TimelineItem.astro`・`Shot.astro`

### 決定

- 引き出し線（線の上の丸から日付への点線）: 札の外（項目そのもの）に置き、札と一緒に下から上がらないようにした。現れるときは、丸が膨らんだあとに丸の側から札の側へ引く
- 年表の帯: 月の見出しの所（見出しの箱の下端より80pxほど下まで。見出しの数字の大きさに合わせて計算する）はその月の色のまま置き、そこから下へ次の月の色へ移す。最後の11月は白へ移し、おわりにの白い地につなぐ。色は oklab で混ぜる
  - 線の上の丸の中身は帯の色から白に変えた。帯の途中の色と丸の中身の色が合わなくなるため
- AI っぽい型を減らした。ユーザーが渡した記事（「AI臭を消したサイトを自力でつくった話」2026-10-31）の型に照らした
  - 説明の文を薄い灰色（#5b6475）にしない。表紙の序文・自己紹介とおわりに・全文の説明を #333c4c にした
  - 浮かせる物だけに2段の影を付けた（スクショの小窓・開いた全文）
  - 見出しは約物の空きを詰め（palt）、言葉の途中で折り返さない（`word-break: auto-phrase`）。表紙の題と節の見出しの字間を 0.04em から 0.02em に詰めた
  - 表紙の題は詰めると1行に収まってしまうので、2つの塊ごとに行を分けると決めた

### 背景

ユーザーが公開中のページを見て指摘した（2026-11-06・5回目）。引き出し線まで下から現れるのが気になる。帯が単色で単調なので「グラデーションやあしらいで」。記事を読んで AI 臭を消してほしい。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 帯ごとに同じ色の濃淡でグラデーションにする | 単色の単調さはあまり変わらない。次の月の色へ移すほうが、年表の「時が進む」に意味が合う |
| 帯に模様（方眼・粒子）を敷く | 札や文字の後ろがうるさくなる。記事も飾りを足すより決めた色で見せる側 |
| 帯の色を減らして1色を主役にする（記事の手法） | 月の6色はユーザーが選んだ配色（004）。蒸し返さない |
| 年表の丸い小窓（白い丸にアイコン）をやめる | スクショの丸い切り抜きの置き場。スクショが入れば写真になる。今はスクショが無いのでアイコンが出ている |
| 表紙の色付きの丸アイコンをやめる | 棒グラフの単位で、表紙の主役。ユーザーが承認した形（005） |

### 影響範囲

- `npm run check:contrast` はグラデーションを見ない。帯の文字色 #1c2433 と、隣り合う月の色の oklab の混ぜ色との差は、全区間で最小 7.94:1 と別に計算した
- 古いブラウザは `in oklab` を読まず、普通の混ぜ方のグラデーションになる

### 検証

- `npm run check` 0件、`npm run build` 成功
- `npm run check:contrast -- http://localhost:4330/tsukutta-2026/`: 幅1280・375・320px とも文字894か所の基準割れ0件
- ヘッドレス Chrome で撮った（幅1440・375）
  - 8月→9月、9月→10月の帯の境目で色がつながる
  - 幅320・375・600・768・899・900・1280・1440px で、月の見出しの下端が色を変え始める所より28px以上上にある。初めは固定の高さ（260px）にしていて、幅600px あたりから見出しの箱がはみ出すと別モデルのレビューで分かり、見出しの大きさに合わせる計算に変えた
  - 項目が現れる途中で、点線は丸の横に止まったまま途中まで引かれている
  - 開いた全文の白い面に影が付き、帯から浮いて見える
