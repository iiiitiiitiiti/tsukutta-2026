## 008. エンドロールを画面いっぱいの映画の形にし、月の帯の高さを固定する

- 日付: 2026-11-06
- 対象: `src/components/Finale.astro`・`MonthBar.astro`・`HeroShelf.astro`・`src/pages/index.astro`・`src/styles/global.css`

### 決定

- 上の月の帯: 帯の高さを12pxで固定し、細い帯は見た目だけ半分に縮める（`scale`）。月ごとの数は消した
  - 前は帯の高さを6pxと12pxの間で動かしていた。切り替えの途中は古い帯と新しい帯がどちらも12pxより低くなり、白い背景の高さが揺れた
- 月の帯は `<div class="page">` の中に入れ、エンドロールの手前で付いてくるのをやめる
- 表紙の棒グラフ: 一番下のアイコンを線から浮かせた（スマホ10px・PC14px）。指したときの輪も線に掛からない
- エンドロール: 黒の画面いっぱい（100svh）にした。流れ方は映画の終わりに合わせた
  - 題の札「今年つくったもの」が真ん中に浮かび、1.3秒止まってから流れ出す
  - 流れる速さは最初から最後まで一定（1秒に90px）。前は終わりに向けてゆっくりにしていた
  - 「2026 18こ作った」の札は行の列から外し、真ん中に来たら止める。上の行は止まらずに上へ抜ける。「おわり」は止まった後に浮かぶ
  - 上下の端はぼかさずに切る
- 近くまでスクロールすると、エンドロールが画面にぴったり収まる所で止まる（`scroll-snap-type: y proximity`）。ページの一番下にも止まる所を置き、最後まで下りられるようにした
- ページの一番下に「上に戻る」ボタンを置いた

### 背景

ユーザーが公開中のページを見て指摘した（2026-11-06・4回目）。「エンドロールのところはブラウザ全体で見せたい。スクロールを止めて上の月は手前までで追従を止める」との指定があった。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| エンドロールの間はスクロールを封じる | 読み手の操作を奪う。キーボードや読み上げで先へ進めなくなる。近くで止まる形なら操作は奪わずに画面に収まる |
| 「止まる所」を必ず効かせる（`mandatory`） | 長い年表の途中でも止まる所へ引き戻されることがある。止まる所の近くだけで効く `proximity` にした |
| 締めの札も行と一緒に止める（前の形） | ユーザーの指定。上の行が画面に残ったまま止まり、映画の終わりらしくない |
| 題の札を出さずに下から流し始める | 映画の終わりらしさが薄い。待ち時間は札が見えている1.3秒だけにした |

### 影響範囲

- `html` の `scroll-padding-top: 72px`（帯で隠れない分）はエンドロールでは要らないので、エンドロールだけ `scroll-margin-top: -72px` で打ち消した
- スクリプトが動かないときは、エンドロールは黒地に全部を並べた形で出る
